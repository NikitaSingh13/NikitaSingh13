# 👋 Hey, I'm Nikita

I'm a **Java Backend Developer** who likes building things that go beyond basic CRUD applications.

My primary stack revolves around **Java + Spring Boot + PostgreSQL/MySQL**, with a growing focus on **microservices, distributed systems, AWS, and AI-powered applications**.

I enjoy the part of development where an idea turns into:

`API → Business Logic → Database → Events → Infrastructure → Production`

I also work with **Angular** when the backend needs a frontend and use **AWS** to take applications from my laptop to the cloud.

> **Backend is my primary focus. AI, cloud and frontend are tools I use to build better systems.**

## 🏥 MediQueue
### AI-Powered Hospital Queue & Appointment Platform

> A microservices-based healthcare platform designed around appointments, queues, authentication and real-time updates.

**Architecture**

```text
                    Angular
                       │
                       ▼
                Spring Cloud Gateway
                       │
          ┌────────────┼────────────┐
          ▼            ▼            ▼
       User         Patient       Triage
      Service       Service       Service
          │            │            │
          └────────────┼────────────┘
                       ▼
                   PostgreSQL
                       │
                ┌──────┴──────┐
                ▼             ▼
              Kafka         Redis
                │
                ▼
        Async Notifications
```

**Built with**

`Java` `Spring Boot` `Spring Cloud` `Spring Security` `JWT`  
`Kafka` `Redis` `PostgreSQL` `Flyway` `Spring AI` `Resilience4j`  
`Angular` `SSE` `Docker`

### Engineering concepts used

- Microservices architecture
- API Gateway
- Service discovery
- JWT authentication & authorization
- Kafka-based asynchronous communication
- Redis caching
- Optimistic locking with `@Version`
- Database migrations using Flyway
- Resilience patterns
- Real-time updates using Server-Sent Events
- AI integration using Spring AI

# 🤖 AI × Backend

One area I'm particularly excited about is combining traditional backend engineering with AI.

Instead of building an AI demo and stopping there, I like thinking about:

```text
       User Request
            │
            ▼
       REST API
            │
            ▼
      Business Logic
            │
       ┌────┴─────┐
       ▼          ▼
   Traditional   AI/LLM
     Logic       Layer
       │          │
       └────┬─────┘
            ▼
         Database
            │
            ▼
         Response
```

The goal is to build **useful software where AI is actually part of the product architecture.**
